# TGbot
Бот показывает:
- баланс TRX;
- баланс USDT (TRC-20);
- последние транзакции адреса.

## Используемые технологии
- Python 3.12
- asyncio
- aiogram 3
- aiohttp
- TronScan API
- TronGrid API
